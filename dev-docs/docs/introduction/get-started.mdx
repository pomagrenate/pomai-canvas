## Overview

Welcome to the **Pomai Whiteboard** developer documentation. Pomai Whiteboard is a next-generation collaborative canvas powered by a C++ WebAssembly rendering engine (`po_render`) and a modern Glassmorphism UI layout.

## How are these docs structured

These docs are focused on developers, and structured in the following way:

- [Introduction](/docs/) — development setup, architecture, and overview.
- [@pomaiwhiteboard/pomaiwhiteboard](/docs/@excalidraw/excalidraw/installation) — docs for monorepo packages and engine integration.
- Editor Internals — Docs describing the C++ WASM bridge, scene graph, and floating dock layout.
